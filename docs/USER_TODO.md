## ✅ 已解除的阻塞

### 1. 整理 30–50 条真实岗位 JD（已完成，2026-08-30）

**完成情况**：已捕获并校验 33 条公开 JD；其中 30 条国内 AI 数据标注岗位族 REAL 样本已入库并用于市场统计。每项市场结论可下钻到原始 JD 片段和公开来源 URL；旧 DEMO 样本已从 REAL 统计中隔离。

正式种子文件：`data/seed/job_postings_ai_data_annotator.json`；来源台账：`docs/JD_SOURCE_REGISTER.md`。

以下说明保留为数据采集规范，供后续扩充样本时使用。

**为什么只能你做**：合规采集需要你的判断。批量爬取招聘网站有 ToS 风险；
唯一免费的中文数据集（textdata.cn，696万条）要求**你本人**加微信申请、
注明姓名-学校-专业、且仅限科研用途，我无法代办。

**卡住什么**：Module 1a（岗位需求分析，Phase 10）——「Python 82%」这类
技能需求百分比必须能追溯到真实 JD 原文，否则整个模块只能是假数据。

**怎么做**：
1. 打开 `data/seed/job_postings_TEMPLATE.json`，按里面的说明填
2. 从 BOSS直聘 / 智联招聘搜「数据标注工程师」「AI训练师」「数据标注员」
3. 每条**原样复制岗位描述**到 `raw_text`，不要改写、不要概括
4. 填完运行 `python scripts/import_postings.py --file 你的文件.json`

**工作量**：约 2–4 小时。N=40 即可用；图表会自动标注样本量，
口径为「样本分析」而非「行业普查」。

**要点**：`raw_text` 必须是原文。技能百分比的可信度完全建立在
「每个数字都能下钻到某条 JD 的某段原文」之上。
