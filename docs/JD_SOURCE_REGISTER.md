1. 第一批正式导入应选 **JD-001 至 JD-030 中的 30 条**，但须先剔除页面失效、重复转载和职责不完整条目。

4. 导入完成后，运行 `POST /api/v1/job-market/ai_data_annotator/analyze` 重建快照；只展示 `REAL` 样本的统计结论，并在界面显示样本量与采集窗口。
